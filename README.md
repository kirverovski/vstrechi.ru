# Встречи (Огонёк)

Мобильное приложение для организации встреч и мероприятий.

## Скачать APK для Android

1. Откройте на телефоне раздел **Releases** и скачайте файл `.apk`
   (прямая ссылка: `.../releases/latest/download/botmeet-1.0.apk`).
2. Разрешите браузеру «Установку из неизвестных источников».
3. Если Play Protect покажет предупреждение — нажмите «Подробнее» → «Установить всё равно».

> Если приложение уже было установлено ранее, а установка не проходит
> («Приложение не установлено»), удалите старую версию и поставьте заново:
> сборка подписана новым ключом. Аккаунт не потеряется — войдите по логину и паролю.

| Параметр | Значение |
|---|---|
| Версия | 1.0 |
| applicationId | `com.botmeet.app` |
| Сервер | https://vstrechi-app.ru |
